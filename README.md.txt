# PatternForge

Synthetic pattern generation toolkit for validation, visualization,
and AI workload simulation.

## Features

- Inverse Incremental Pattern
- Colorbar Pattern
- AI Workload Pattern

## Vision

PatternForge aims to become a modular framework for generating
high-diversity synthetic workloads and validation patterns.

## Installation

pip install -r requirements.txt

## Usage

python generators/ai_workload_pattern.py
